# kedger v0.1.1 — Launch release (2026-08-09)

kedger v0.1.1 — Launch-ready engineering-memory CLI for coding agents (hooks → Anchors → sealed .kxp handoff)

What’s this
kedger is a local-first CLI that helps coding agents capture, organize, and export engineering memory. This release is focused on launch readiness with durable handoff tools, improved hooks, and transfer workflows so teams can dogfood sealed pack handoffs end-to-end.

Highlights
- `kedger init` — keys + repo policy + optional IDE hook install
- `kedger hooks install` — copy Cursor/Claude packs into the caller repo (cwd/git root)
- Peer handoff surface: `kedger peer card|add|send|open` for two-person agent transfer
- Dual-layer handoff: Anchors + agent activity (lines, files, tool failures)
- Lossless zlib transcript archive + `kedger transcript stats|show|decompress`
- `kedger pack-export` — export `.kxp` (+ sidecar) for transfer
- `hydrate --pack` durable import (Anchors + activity + transcript + local HEAD)
- `cognify --promote` with auto-promote & soft-boundary promote
- `keys import-recipient` for peer TOFU
- Robust QA scripts and CI: doctor, smoke_transfer, smoke_wheel_install, and GitHub Actions (`pytest -q`)

Notes
- This is a launch-ready surface meant for dogfooding sealed person-to-person handoff. Some advanced phases (LLM distill, sync, MCP) remain deferred and will be tracked separately.
- Expect rapid iteration; breaking CLI/API changes will be documented in future changelogs.

Quickstart
- Clone: git clone https://github.com/gaganTakIITD/kedger
- Install (from source): python -m pip install -e ./kedger
- Try the CLI:
  - kedger init
  - kedger hooks install
  - kedger peer add "recipient"
  - kedger pack-export --out mymemory.kxp
