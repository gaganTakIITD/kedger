# kedger v0.2.0 — Beta (2026-09-05)

kedger v0.2.0 — Beta production path: P0–P3 (trustworthy tests, prompt inject, capture honesty, handoff quality)

## Highlights

- **P0:** Time-safe eval fixtures + fail-soft hooks (never block prompts when kedger missing)
- **P1:** Per-prompt hydrate inject + minimal MCP (`hydrate`, `anchors_get`); auto MCP config on `init`/`hooks install`; doctor warns on missing registration
- **P2:** Honest claim extract, consolidate near-dups, postToolUse capture, surface-K hydrate
- **P3:** Seed-IDF retrieve, dual-path Evidence packing, delay-k L0 eviction, doctor + peer_trial
